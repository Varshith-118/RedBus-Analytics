# RedBus Route & Pricing Analytics

A Python and Excel project that cleans and analyzes bus booking data and compares operator pricing and availability across cities.

## Overview
- Built a Python data pipeline to clean and structure 11 linked datasets: 5,000 bookings across 30 operators, 70 routes, 160 buses and 1,300 customers
- Standardized formats, removed duplicates and resolved missing values to produce an accurate dataset
- Performed exploratory data analysis across booking, route, operator and payment tables to find patterns in pricing, ratings and availability
- Used openpyxl to automate structured Excel reports and PivotTables comparing operator pricing and availability across 10+ cities

## Tech Stack
Python (Pandas, openpyxl), Microsoft Excel (PivotTables)
